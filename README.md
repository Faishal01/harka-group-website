# Harka Group

## 📁 Project Structure

This project is a Bun workspaces monorepo containing:
- `apps/user`: The user-facing website.
- `apps/admin`: The admin dashboard for managing inventory.
- `packages/db`: Shared database schema and logic.

## 🛠️ Technologies Used

- **Astro**: The core framework for building fast, content-focused websites.
- **TailwindCSS**: A utility-first CSS framework for rapid UI development.
- **Embla Carousel**: A modern slider library for creating responsive sliders.
- **Bun**: Fast all-in-one JavaScript runtime and package manager.
- **Cloudflare D1**: Serverless SQL database.
- **Drizzle ORM**: Headless TypeScript ORM.
- **Cloudflare R2**: Object storage for car images and media.

## ☁️ Deployment

The site is deployed as Cloudflare Workers.
